# Labeling the PDFs -- instructions

Thanks for helping review these documents! This should take a few minutes
per file. No installation and no technical setup needed.

## 1. Open the tool

Double-click **`corpus-labeler`** (Windows: `corpus-labeler.exe`).

Your computer will probably show a warning the first time, because this
program didn't come from an app store:

- **Windows:** a blue "Windows protected your PC" box appears. Click
  **More info**, then **Run anyway**.
- **Mac:** you'll see "cannot be opened because the developer cannot be
  verified." Right-click (or Control-click) the file, choose **Open**, then
  confirm **Open** in the dialog that appears.

This warning is expected for a program shared outside an app store. It's
safe to continue -- you're running a copy of a tool we built ourselves.

## 2. Pick a PDF

A file window opens automatically. Pick one of the PDFs from the folder you
were given and click **Open**. A browser tab will open showing the document.

## 3. Label the document

Draw a box around anything worth flagging, then tag it (what kind of thing
it is, whether it's sensitive, and what should happen to it). Add a short
note if it's unclear at a glance. You can edit or remove anything you've
added before exporting.

Work through as much of the document as you're comfortable with -- there's
no strict requirement to catch everything.

## 4. Export

Click **Export** when you're done with a document. A file appears in a new
`labeled-output` folder that shows up right next to the program you
double-clicked. You don't need to do anything with that folder yourself.

Repeat steps 2-4 for each PDF you were given.

## 5. Send it back

Once you've gone through the documents, reply to the email you got this
from and attach everything in the `labeled-output` folder. Those files are
small, so a normal email attachment is fine.

If anything looks broken or confusing at any point, stop and let us know
rather than guessing -- happy to hop on a call.
